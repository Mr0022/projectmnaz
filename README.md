# کاردرمانی ذهنی کودکان — مهرناز افشار

صفحه‌ی تک‌صفحه‌ای (Single Page) فارسی و راست‌چین برای معرفی خدمات کاردرمانی ذهنی کودکان.
با هر اسکرول، صفحه دقیقاً به بخش بعدی منتقل می‌شود و هر بخش یک تمرین تعاملی دارد.

## بخش‌ها

| # | بخش | تمرین تعاملی |
|---|------|---------------|
| ۰ | خانه | معرفی و انیمیشن ورود |
| ۱ | دست‌ورزی (ترسیم) | تخته‌ی نقاشی با خط‌چین راهنما، پالت رنگ و ضخامت قلم |
| ۲ | شناختی | بازی حافظه (پیدا کردن جفت‌ها) |
| ۳ | بینایی ـ شنیداری | ببین، بشنو، تکرار کن (توالی رنگ و صدا) |
| ۴ | مهارت‌های اجتماعی | کارت‌های احساس (برگرداندن کارت) |
| ۵ | بازی‌درمانی | ترکاندن حباب با امتیاز |
| ۶ | درکی‌ـ‌حرکتی و سنجش مدرسه | جاگذاری اشکال با کشیدن و رها کردن |
| ۷ | رفتاردرمانی | جدول ستاره |
| ۸ | ارتباط با ما | دعوت به رزرو نوبت |

## اجرا

فایل‌ها ایستا هستند و به هیچ ابزار ساختی نیاز ندارند:

```bash
# باز کردن مستقیم
open index.html

# یا اجرای یک سرور محلی
npx http-server -p 8080
```

برای انتشار روی **GitHub Pages** کافی است شاخه‌ی موردنظر در تنظیمات مخزن فعال شود؛
`index.html` در ریشه قرار دارد.

## ساختار

```
index.html          محتوای بخش‌ها (فارسی، dir="rtl")
assets/styles.css   طراحی، رنگ‌بندی هر بخش، چیدمان واکنش‌گرا
assets/app.js       پیمایش بخش‌به‌بخش و منطق بازی‌ها
```

## نکات فنی

- **پیمایش:** ترکیب `scroll-snap` در CSS با کنترل چرخ ماوس در JS؛ هر حرکت اسکرول (حتی پرتاب سریع)
  فقط یک بخش جلو می‌رود. کلیدهای ↑ ↓ Page Up/Down و فاصله هم کار می‌کنند.
  اگر محتوای بخشی در صفحه جا نشود (نمایشگر بسیار کوتاه)، این کنترل به‌طور خودکار غیرفعال
  و اسکرول عادی می‌شود.
- **واکنش‌گرایی:** ارتفاع هر بخش در گوشی، تبلت و دسکتاپ دقیقاً اندازه‌ی یک صفحه است.
- **صدا:** با Web Audio تولید می‌شود و فقط پس از اولین تعامل کاربر پخش می‌شود (بدون فایل صوتی).
- **دسترسی‌پذیری:** ناوبری با صفحه‌کلید، برچسب‌های ARIA و پشتیبانی از
  `prefers-reduced-motion` برای کاهش انیمیشن.
- **قلم:** Vazirmatn از Google Fonts، با جایگزین سیستمی در صورت نبود اینترنت.

## سفارشی‌سازی

- **متن‌ها:** مستقیماً در `index.html` قابل ویرایش‌اند.
- **رنگ هر بخش:** روی هر `<section class="sec">` با متغیرهای `--a`، `--b`، `--bg1` و `--bg2` تعیین می‌شود.
- **راه‌های ارتباطی:** در بخش «ارتباط با ما»، دو لینک `data-contact` با `href="#"` قرار دارند؛
  شماره‌ی تماس (`tel:`) و نشانی اینستاگرام را جایگزین کنید.
